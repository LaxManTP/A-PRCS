Anti-Poaching Response Companion System (A-PRCS) is an AI powered environmental surveillance and alert system made to assist conservation groups in low infrastructure areas. Meerkat(RPI 02w), the forward deployed edge sensing node uses YOLO26n trained on African wildlife, firearms, people and drones to analyze the risk of a scene. Meerkat then relays the risk scores back to Ivor(RPI 4/5), which is a cyberdeck carried by field operators to interface with the sensors.



Current Stage: Early Dev Meerkat that can ID pistols and African Wildlife



Future Stages:

* Add drones, people, rifle to Meerkat application
* Improve risk score logging
* Ivor
* Initial Comms 
* Secure system
* Investigate housing options for computers
